# Module 2 – Security Assessments

## 📘 Overview
This module covers key concepts in cybersecurity assessments, including vulnerability scanning, network diagnostic tools, and security automation systems used to detect and respond to threats.

---

## 📂 Contents

- Module 2.1 – Security Assessments  
  (Vulnerability Scanners, Scan Types, Command Line Tools, SIEM, SOAR)

---

## 🛡️ Topics Covered

### 🔍 Vulnerability Scanning
- Identifying system and network weaknesses
- Detecting misconfigurations, weak passwords, and missing patches
- Tools: Nessus, Nmap, Retina

### 🌐 Types of Scans
- Network scans
- Application scans
- Web application scans
- Credentialed vs non-credentialed scans

### 🖥️ Network Tools
- ping, ipconfig, tracert
- nslookup, netstat
- nmap, arp, netcat

### 🔐 Security Automation
- SIEM: Detects and analyzes security events
- SOAR: Automates responses and incident handling

---

## 🎯 Key Skills Learned
- Network troubleshooting fundamentals
- Vulnerability identification methods
- Understanding of SIEM and SOAR systems
- Security monitoring and response basics

---

## 🧠 Key Takeaways
- Vulnerability scanners help identify risks before attackers do
- Command-line tools are essential for diagnostics and security analysis
- SIEM focuses on detection and monitoring
- SOAR focuses on automation and response

---

## 🚀 Purpose
This module builds foundational knowledge in cybersecurity operations, preparing for real-world security monitoring and threat response roles.
