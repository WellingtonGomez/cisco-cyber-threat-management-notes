## Module 1.3 – IT Security Management Framework

### 📌 Key Concepts

#### ISO/IEC 27000 Framework

* International standard for Information Security Management Systems (ISMS).
* Helps organizations improve information security through administrative, technical, and operational controls.
* Organized into 12 cybersecurity domains that work together to protect information assets.

---

### 🔐 The 12 Domains of Cybersecurity

1. Risk Assessment

   * Identifies and evaluates risks and threats.

2. Security Policy

   * Defines rules, responsibilities, and acceptable use of data.

3. Organization of Information Security

   * Establishes governance and security management structure.

4. Asset Management

   * Inventory and classification of information assets.

5. Human Resources Security

   * Security procedures for employees before, during, and after employment.

6. Physical and Environmental Security

   * Protects facilities, equipment, and information.

7. Communications and Operations Management

   * Manages security controls for systems and networks.

8. Information Systems Acquisition, Development, and Maintenance

   * Integrates security throughout system lifecycles.

9. Access Control

   * Restricts unauthorized access to systems and data.

10. Information Security Incident Management

    * Handles detection, reporting, and response to security incidents.

11. Business Continuity Management

    * Ensures recovery of critical operations after disruptions.

12. Compliance

    * Ensures adherence to policies, regulations, and standards.

---

### 🎯 Control Objectives vs Controls

#### Control Objectives

* High-level security requirements.
* Define what an organization wants to achieve.
* Used during ISO 27001 audits.

#### Controls

* Specific actions used to achieve control objectives.
* Provide implementation guidance.
* Can be achieved through multiple methods.

Example:

* Objective: Prevent unauthorized access.
* Control: Require strong passwords with letters, numbers, and symbols.

---

### 🛡️ CIA Triad and ISO 27000

Organizations prioritize security differently based on business needs:

#### Confidentiality

* Protects information from unauthorized access.

#### Integrity

* Ensures data remains accurate and trustworthy.

#### Availability

* Ensures systems and data remain accessible.

Examples:

* Google prioritizes Confidentiality and Availability.
* Amazon prioritizes Availability because downtime impacts sales.

---

### 💾 States of Data

#### Data at Rest

* Stored data on devices or databases.

#### Data in Transit

* Data moving across networks.

#### Data in Process

* Data actively being used or modified.

Different cybersecurity teams may be responsible for securing each state.

---

### 🏢 NIST National Cybersecurity Workforce Framework

#### Operate and Maintain

* Supports and maintains IT systems.

#### Protect and Defend

* Identifies and mitigates threats.

#### Investigate

* Examines cyber incidents and attacks.

#### Collect and Operate

* Conducts specialized cybersecurity operations.

#### Analyze

* Evaluates cybersecurity intelligence.

#### Oversee and Govern

* Provides leadership and policy direction.

#### Securely Provision

* Designs and builds secure systems.

---

### 🔒 CIS Critical Security Controls

#### Basic Controls

* Hardware inventory
* Software inventory
* Vulnerability management
* Administrative privilege control
* Secure configurations
* Audit log monitoring

#### Foundational Controls

* Email and browser protection
* Malware defense
* Network security controls
* Data recovery
* Boundary defense
* Wireless security
* Access control

#### Organizational Controls

* Security awareness training
* Application security
* Incident response management
* Penetration testing and red team exercises

---

### ☁️ Cloud Controls Matrix (CCM)

Created by the Cloud Security Alliance (CSA).

Purpose:

* Provides cloud security guidance.
* Maps cloud security controls to industry standards.
* Helps organizations evaluate cloud provider security.

Key Fact:

* Contains 197 control objectives across 17 cloud security domains.

---

### 👨‍💻 Cybersecurity Roles

#### Cybersecurity Analyst 🔍

* Monitors systems
* Investigates incidents
* Applies security patches

#### Cybersecurity Engineer 🛠️

* Builds security solutions
* Configures firewalls and tools
* Implements security policies

#### Penetration Tester 🎯

* Performs vulnerability testing
* Conducts social engineering assessments
* Identifies weaknesses and recommends improvements

---

### 🎯 Key Takeaway

The ISO 27000 framework provides a structured approach to managing cybersecurity through domains, control objectives, and controls. Organizations use these frameworks alongside NIST, CIS Controls, and cloud security standards to protect data confidentiality, integrity, and availability while ensuring compliance and business continuity.
