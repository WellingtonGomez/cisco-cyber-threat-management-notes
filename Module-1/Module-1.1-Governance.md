# Module 1.1 - Governance

## Overview

This module introduced IT governance, data governance roles, cybersecurity policies, and security policy frameworks. Effective governance ensures cybersecurity decisions align with business objectives, regulatory requirements, and risk management practices.

---

## IT Security Governance

IT security governance establishes who is responsible for making cybersecurity decisions within an organization.

### Key Objectives

* Demonstrate accountability
* Provide security oversight
* Mitigate cybersecurity risks
* Align security strategies with business goals
* Ensure regulatory compliance

### Governance vs. Management

**IT Security Governance**

* Determines who makes security decisions
* Provides oversight and accountability

**IT Security Management**

* Implements security controls
* Manages day-to-day security operations

---

## Data Governance Roles

### Data Owner

* Classifies information assets
* Determines access requirements
* Ensures compliance with policies

### Data Controller

* Determines how and why personal data is processed

### Data Processor

* Processes data on behalf of the data controller

### Data Custodian

* Implements technical controls
* Protects and maintains data

### Data Steward

* Ensures data supports business needs
* Maintains regulatory compliance

### Data Protection Officer (DPO)

* Oversees organizational data protection strategies

---

## Cybersecurity Policies

A cybersecurity policy is a high-level document that defines an organization's security goals, responsibilities, and requirements.

### Purpose

* Demonstrates commitment to security
* Establishes security standards
* Ensures consistency across systems
* Defines consequences for violations
* Supports security teams and management

---

## Types of Cybersecurity Policies

### Cybersecurity Policy

The master policy that serves as the blueprint for the organization's security program.

### System-Specific Policy

Defines security requirements for specific systems, devices, software, and hardware.

**Example:**

* Firewall Policy

### Issue-Specific Policy

Addresses specific operational issues or security concerns.

**Example:**

* Email and Internet Acceptable Use Policy

---

## Common Security Policies

### Identification and Authentication Policy

Defines who can access network resources and how users are verified.

### Password Policy

Establishes password requirements and change schedules.

### Acceptable Use Policy (AUP)

Defines proper use of company systems and resources.

### Remote Access Policy

Specifies requirements for connecting to company networks remotely.

### Network Maintenance Policy

Provides guidance for updating systems and applications.

### Incident Handling Policy

Defines procedures for reporting and responding to security incidents.

### Data Policy

Defines data classification, storage, handling, and disposal requirements.

### Credential Policy

Establishes rules for creating and managing credentials.

### Organizational Policy

Provides guidance for organizational processes such as:

* Change Management
* Change Control
* Asset Management

---

## Key Takeaways

* Governance establishes accountability for cybersecurity decisions.
* Data governance ensures information is properly managed and protected.
* Cybersecurity policies provide a framework for organizational security.
* Clear security policies reduce risk and improve compliance.
* Security governance must align with business objectives and regulatory requirements.
